\section{Concept}

GeoMedia found spaces within Online Social Networks, based on a geographical map, allows to upload and share content as form of post, which serve as a container for the information that users want to provide.

The original idea was just realted to textual comments (\textit{GeoComments}), moreover expanded with images and then every kind of media, and finally enriched with collections that works as layers for provide more complex and characteristics use cases for limitation scope.

To accomplish the idea behind the app, different technlogogies and architecture must be established.
The client layer, which represent the single point of interaction of the users, must be a mobile application that allows users to move across real world and through GPS interact with the application layer that provide the logic and coordinate which content users can see based on their position and others metadata.


\section{Collections}

Collections represent containers for posts, which users can create and customize with an icon and a color thus to quickly recognize the collection among others.

Users can also define the visibility of the collections for both:
\begin{itemize}
    \item \textbf{Users}: that define which users are enabled to see the collection, in each section (map viewer, collections list)
    \item \textbf{Time}: by limiting the collection visibility between two date range and creation a repetition of the range, montly (each month within the days defined) or yearly (the specific month and days defined)
\end{itemize}

On the otherside, the owner of the collection, can define also which creators are allowed to use it to put content in it.
This provide the granuality to divide viewers to creators, enriching the experiences and enabling the platform and users to monitor and limit content as they like.

For each collection, the owner can enable or not, remote posting, which enable or disable the location picking in creation of the post. This feature make the platform more relatable for different scanario, such as restaurant reviews, traffic conditions, real time information, avoiding unrelated posts thus to make the social more real and integrated within the real word.

In the end, to every collection can be assigned an unlimited number of hasthag, which server as classification topic for the collection, in order to helps users to discover differents layers and contents.


\section{Map}

The Map section is the core component of GeoMedia, by providing a geographic map enriched with posts to the specific coordinate where others users has created a post (or picked if the collection is enabled to remote posting). The marker has the color of the collection thus to recall it, and by tapping it, it shows the post in full display. For each posts users can check the profile of the creator and see the post accessible from the current location and enabled to it, or can just express an interaction by liking the post.
In the end, for each post, users viewer can download the content uploaded if it present a media file attached, indipendently of the extension that it has.
